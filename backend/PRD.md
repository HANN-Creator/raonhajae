# PRD — 청도 여행 길 추천 에이전트

## 1. 목적

청도 방문자가 도착 날짜·시각·여행 속도를 입력하면 7번 농어촌버스로 갈 수 있는 반나절 코스를 추천한다. 추천 결과에는 청도 출발·귀환 시각, 방문 순서, 환승·도보 여유, 원문 시간표 링크를 함께 표시한다.

## 2. 사용자와 핵심 흐름

- **대중교통 여행자**: 청도 도착 시각에 맞는 왕복 코스를 찾는다.
- **여유로운 여행자**: 천천히 둘러볼 수 있는 일정이 버스 귀환 시각과 충돌하지 않는지 확인한다.
- **비 오는 날의 여행자**: 실외 산책을 줄인 와인터널 중심 코스를 선택할 수 있다.

사용자는 `내 코스`에서 조건을 입력하고 `추천 코스`로 이동한다. 화면은 서버의 후보 계산과 에이전트 선택을 기다렸다가 추천 일정과 그 이유를 표시한다. Copilot을 사용할 수 없으면 시간표 기반 규칙 추천을 표시한다.

## 3. 현재 범위

1. 청도군 공개 **7번 버스 시간표**에서 와인터널 구간 왕복 후보를 만든다.
2. 청도 도착 후 승차 위치 이동 20분, 관광지 하차 후 이동 15분, 귀환 전 이동 여유를 반영한다.
3. `와인터널·송금마을` 및 `와인터널 중심` 후보를 만든다. 후보가 여러 개이면 GitHub Copilot SDK를 Microsoft Agent Framework의 `GitHubCopilotAgent`에서 호출하여 하나를 선택한다.
4. 선택 결과는 서버가 이미 계산한 후보 ID와 일치할 때만 채택한다. 일정의 버스 시각과 방문 순서는 서버가 계산한 값을 그대로 사용한다.
5. 강수 예보를 사용할 수 있으면 후보 선택에 반영한다. 예보가 없으면 시간표와 여행 속도만 사용한다.
6. 추천 방식(`copilot` 또는 `rules`), 시간표 원문, 데이터 상태(`live` 또는 `fallback`)를 응답과 화면에서 구분한다.

## 4. 제품 요구사항

| ID | 요구사항 | 완료 기준 |
| --- | --- | --- |
| R1 | 날짜·도착 시각·속도 입력 | 잘못된 값은 HTTP 400으로 거절하고 외부 조회를 하지 않는다. |
| R2 | 가능한 왕복 일정 계산 | 출발은 청도 도착 20분 이후이고 모든 버스 시각은 공식 조회 또는 명시된 저장 시간표에서 온다. |
| R3 | 에이전트 추천 | Copilot이 **실제로** 응답해 유효한 후보를 고른 경우에만 `engine: copilot`을 반환한다. |
| R4 | 안전한 실패 처리 | 인증·네트워크·모델 오류 또는 잘못된 후보 ID가 오면 규칙 추천으로 전환하고 그 상태를 알린다. |
| R5 | 출처 표시 | 실시간 버스 위치나 실시간 운행 정보인 것처럼 표시하지 않는다. |
| R6 | 화면 연결 | `내 코스` 제출 → API 요청 → 로딩 → 추천 결과를 React에서 확인할 수 있다. |

## 5. 비범위와 다음 단계

현재 추천은 **청도역 인근 ↔ 와인터널 7번 버스 반나절 코스**에 한정한다. 지도 위 선은 실제 버스 노선 또는 길 안내가 아니다. 정류장 위치, 보행 경로, 운영시간, 요금·할인, 실시간 버스 운행은 별도 확인이 필요하다. 다른 관광지·교통수단을 추천하려면 검증 가능한 노선/도보 경로 데이터와 장소 영업시간을 먼저 연결한다.

## 6. 성공 지표

- 유효한 요청에서 추천 또는 명확한 `no_route` 응답을 반환한다.
- 모델 출력이 시간표에 없는 시각을 일정에 추가하는 사례 0건.
- Copilot 사용 여부가 응답·화면에서 사실과 일치한다.
- 서버 단위/API 테스트와 React 빌드가 통과한다.
