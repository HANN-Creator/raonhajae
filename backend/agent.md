# 청도 길 추천 에이전트 계약

## 정체성과 역할

**이름:** `CheongdoRouteSelector`
**프레임워크:** Microsoft Agent Framework `GitHubCopilotAgent`
**모델 연결:** GitHub Copilot SDK `CopilotClient`

에이전트의 유일한 책임은 서버가 검증한 여행 후보 중 `candidate_id` 하나를 고르는 것이다. 버스 시각이나 지도를 생성하지 않는다. 실제 시스템 지시문은 `route_agent.py`의 `AGENT_INSTRUCTIONS`에 있다.

## 입력

서버가 다음 정보만 JSON으로 전달한다.

- 청도 도착 시각, 여행 속도
- 후보별 ID, 코스 이름, 버스 출발·귀환 시각, 대기·귀환 여유 분
- 후보의 야외 산책 여부와 해당 시간대 강수 확률(있을 때)

사용자 자유 문장, 외부 페이지 본문, 인증키, 지출 내역은 전달하지 않는다.

## 출력

```json
{"candidate_id":"1120-1445-full"}
```

정확히 하나의 JSON 객체만 허용한다. `candidate_id` 이외의 필드나 존재하지 않는 ID는 거절한다. 최종 일정은 선택된 후보에서 서버가 다시 조립한다.

## 선택 규칙

1. 강수 확률이 60% 미만이거나 예보가 없으면 `full`(와인터널·송금마을)을 우선한다.
2. 강수 확률이 60% 이상이면 실외 산책이 없는 `wine-only`를 우선한다.
3. 같은 유형이면 청도 도착 후 대기가 짧고 귀환 버스 전 이동 여유가 충분한 후보를 고른다.
4. 입력에 없는 버스, 장소, 시간, 할인, 운영시간은 추측하지 않는다.

## 권한과 실패 규칙

Copilot SDK는 `mode="empty"`로 시작하고 세션의 `available_tools`는 빈 목록이다. Agent Framework는 별도 권한 승인을 받지 않으면 요청을 거부한다. 외부 데이터 조회는 서버의 고정된 시간표·날씨 함수만 수행한다.

모델 응답이 없거나 잘못되면 `route_agent.py`의 규칙 선택으로 대체한다. `agent.engine`은 실제로 유효한 모델 선택이 있었을 때에만 `copilot`이다. 버스 데이터가 저장본이면 `source.status: fallback`으로 알리고 방문 전 원문 확인을 안내한다.

## 변경 시 확인할 것

후보 생성 규칙이나 프롬프트를 바꾸면 `tests/test_route_agent.py`에서 시간표 일치, 버퍼, 잘못된 모델 출력, 실패 대체를 검증한다. 신규 목적지·이동수단을 추가하기 전에는 그 구간의 검증 가능한 시간표·정류장·보행 경로를 확보한다.
